# Little Lampkeepers interior typefaces

Vendored SIL Open Font License faces. Code owns every title, verse, instruction,
page number, and label. Image models must not render type.

| Role | Face | File |
| --- | --- | --- |
| Display titles | Bubblegum Sans | `BubblegumSans-Regular.ttf` |
| Mission kickers | Sniglet | `Sniglet-Regular.ttf`, `Sniglet-ExtraBold.ttf` |
| Child instructions / body | Andika | `Andika-Regular.ttf`, `Andika-Bold.ttf`, `Andika-Italic.ttf`, `Andika-BoldItalic.ttf` |
| Prayer / handwritten prompts | Patrick Hand | `PatrickHand-Regular.ttf` |

Helvetica is forbidden as a consumer-facing primary face.

Licenses: `OFL-*.txt` in this folder.
